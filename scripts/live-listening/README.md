# Listening evidence

The hosted gate retains its original three mandatory journeys and additionally requires warm Replay and saved P2 Scripture under isolated browser offline simulation. Every playback assertion uses native clocks and canonical media hashes. Offline simulation is not a physical-device or disconnected-network claim. The controlled protocol fixture is explicitly separate from the hosted Worker: it holds a response pending and observes real native media after terminal completion for OFF→ON, actual Cancel preparation, and manual Ready→Play.

`persona-summary.mjs` turns the Playwright report into compact observations keyed by full source commit, environment, and scenario. Missing scenarios remain `not-covered`; failed assertions retain the failure. Visible notices are observations, never invented sentiment or user feedback. The workflow automatically reads prior immutable same-environment records from the fixed evidence branch and selects the latest prior run per scenario. It validates path identity and Git blob hashes before outcome-only comparison. Missing or invalid history is explicitly not-covered. Hosted PASS requires the existing full receipt verifier to pass; controlled PASS requires verifyControlled. All three controlled modes are separately archived with fixture scope, never as hosted outcomes. The attached raw evidence is SHA-256 bound; traces/video remain finite workflow artifacts.

After independent review and integration, the separate `archive-persona` job writes only to `klappy/fia-app` branch `fia-persona-evidence`. It never updates a deployment branch. Paths are `<fullcommit>/<environment>/<runID>-<attempt>/<sha256(scenario)>.json`. The branch is initialized with an empty tree, then each append inherits the existing tree. Existing identical bytes are idempotent; conflicting bytes fail. Updates use one parent and `force:false`; the workflow serializes archive jobs. There are no deletes or overwrites.

The writer runs only on trusted push or workflow_dispatch on main/staging/production, checks out the triggering trusted SHA rather than a requested commit, and receives write permission only in that job. Downloaded report data is never executed. Missing evidence is archived as not-covered with an explicit failing disposition; missing archive is a job failure. Normal summaries contain no large trace bodies, local screenshot paths, credentials, or human sentiment claims. This candidate does not itself enable or execute remote writes before review/integration.
