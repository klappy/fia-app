# Known-original streaming acquisition

This opt-in module follows cookbook PR173, `LONG-ORIGINALS-RECIPE.md` SHA `7c25a8ba8cdbc7fdb3b4ffeafbc604a0c6d1bd153d4b8ce8f2c7d067c02d6491`. Base source: `a478f1903c41210838c0b6b7e4174ce435a5877c`. It does not change the existing 2 MiB original store, discovery adapter, serving route, ASR, decoder, controller or release configuration.

`createKnownSourceAcquisition({bucket, storage, policy, fetchSource?, makeStream?, totalMs?, progressMs?})` requires trusted server-only policy `{policy:'fia-known-long-original@1', url, sourceVersion, sha256, bytes}`. `sourceVersion` is the caller's independently verified publisher/source version; it must not silently substitute a presentation snapshot revision. Only exact HTTPS URLs without credentials, query, or fragment are accepted. This is not a public URL API or an unknown-hash discovery interface. The caller must route the immutable source identity to the same durable coordinator. `storage` requires SQLite-style transactions with get/put; the runtime requires Workers `nodejs_compat` SHA-256 and `FixedLengthStream` plus R2 conditional writes.

`acquire(signal?)` claims before network access. Other requests return the persisted preparing/uncertain state without duplicate transfer. Known size is at most 8 MiB. Defaults are 120 seconds total and 15 seconds without body/write progress; supplied test bounds can only tighten these. Content-Length may be missing; when present it must match the pin, and actual length/hash always must match. Responses must be 200 audio/mpeg with manual redirect handling. Transfer retains at most one accepted input chunk (1 MiB ceiling), writes 64 KiB subarray slices with backpressure, and records observed input chunk size. This is not a measured total runtime-memory ceiling; platform buffers are unmeasured.

Original bytes stage under an attempt-specific quarantine key. Only validated bytes can create the unchanged `originals/sha256/<SHA>.mp3` key. A competing winner is streamed and rehashed; corrupt existing objects are never overwritten. Exact append-only URL/version references and an attempt-bound acquisition receipt precede durable completion. Final commit checks the live durable attempt and cancellation. A late R2 operation can leave an orphan after timeout but cannot complete the attempt. No automatic quarantine deletion is attempted, since a timed-out writer may still be running. No cron or hosted action is included.

Completed reuse streams and verifies the retained original, reference and receipt before returning its artifact, with no publisher GET. A corrupted warm artifact fails closed. Uncertain attempts never automatically retry; `reconcile({attemptId,revision})` only verifies retained original/quarantine evidence and reports uncertainty. It does not unlock an active writer, adopt orphan objects, promote an incomplete receipt or authorize serving. Recovery/promotion and bounded cleanup need a separate reviewed control path. There is no public route, rights/known-bad eligibility evaluation, unknown-length/hash acquisition, 600-second decode proof, recognition, or timing acceptance in this increment.

Run the focused tests with the existing Worker dependency package selected through `FIA_WORKER_DEPENDENCIES`:

```
node --test tests/preparation-executor/known-source-stream.test.mjs
```

The tests use actual local Miniflare SQLite/R2 and simulated publisher streams. They cover the exact cap and excess, absent/false length, truncated bodies, MIME/redirect refusal, bad bytes, progress and total deadlines, cancellation, one concurrent owner, interrupted publication, create-only winner verification, and restart with zero publisher requests. An optional `FIA_RETAINED_BSB` filesystem path enables the existing retained-file proof: 5,135,362 bytes, SHA `ad82d1a49f696a421f87a0ba54e7079c35fb403462c1e2e335a1fabe515363ec`. The test rehashes those exact local bytes, stages them as a simulated publisher body, and proves immutable R2 retention and offline restart reuse. Its test input buffer is outside the acquisition implementation; it makes no network request, decode/duration/memory/ASR or hosted deployment claim. No original recording is committed.
