# Pinned acoustic measurements

`signal-measure.py --input job.json --output result.json` measures retained source bytes without fetching audio or running recognition. The job pins source, raw-recognition and alignment files by exact SHA-256 and source length. The program decodes the hashed in-memory source through PyAV to mono 16 kHz float32 and requires the raw-recognition PCM hash and sample count to reproduce exactly. It records actual source codec/rate/channel metadata and runtime versions.

The reviewed procedure is cookbook PR177, commit `7c753cf90962bb634a24e86d22f03c2e20c15299`. For a uniquely matched candidate unit, it examines only the interval between its complete ASR word envelope and the adjacent word envelopes. Six or more consecutive 10 ms frames below −45 dBFS form a candidate quiet run. Multiple qualifying runs block selection and remain visible. A single run yields a midpoint plus a centered 60 ms recheck. Margins refer to the selected quiet run, not the wider estimated speech interval.

Each cut includes local RMS landmarks, and distributed anchors at 10% through 90% of duration include exact sample offsets and linear RMS values. These enable independent decoder comparisons without treating silence as an identifiable clock landmark. Source, decoded duration, word, unit, input and output limits remain bounded. Current source cap is 2 MiB and decoded duration cap is 600 seconds; the larger-original recipe is not implemented here.

All outputs remain measurements. Silence does not prove word identity, ASR boundaries or calibrated confidence. No accepted playback ranges are emitted. A browser comparison must independently pin this result, verify source bytes, measure its actual profile and qualify source-to-browser and native media-clock mappings before interpreting native stop times as acoustic margins. A best-fit landmark offset by itself does not establish unique mapping; periodic or silent energy patterns can remain ambiguous. Repeated local trials are observations, not universal worst-case or device claims.

The retained Mark 1:21–28 S01 example reproduces 830,434 mono samples at 16 kHz. Its source is 48 kHz MP3, unlike the earlier 44.1 kHz source, so earlier profile qualification cannot simply be inherited. Three exact-correspondence candidates have one measured quiet run at each edge; other units remain unmeasured. A separate local browser probe observed matching sample count and nominal zero-shift landmark fits but different PCM bytes. Native clock qualification and recognition confidence remain open, independently of original-source eligibility.

Run the ten identity, PCM, ambiguity and margin tests with the retained Python runtime that provides PyAV and NumPy: `python tests/preparation-executor/test_signal_measure.py`. Synthetic waveform tests include replacing the source path after hashing to prove decoding uses pinned bytes. The script is an offline reference measurement capability, not a hosted route or production deployment.
