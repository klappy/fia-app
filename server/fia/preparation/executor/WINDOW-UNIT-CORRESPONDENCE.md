# Reversible per-unit window correspondence

`correspondWindowUnits({canonicalBytes, canonicalSha256, plan, records, candidateSpans})` is a pure, environment-neutral lexical evidence module. It is not installed in the Worker/factory. The caller supplies a trusted canonical manifest with schema `fia-canonical-correspondence-units@1`, identity, whole-guide `scriptSha256`, and units `{activityId,sourceUnitId,sourceTextSha256,text}`. The exact manifest byte digest is independently checked; each text digest is recomputed. This does not authenticate an arbitrary caller's manifest as publication authority.

Raw records are the planner's completed records `{state,windowSha256,rawSha256,rawBytes}`. Bytes are captured before awaits, rehashed, checked against the canonical plan/window/model identity and reprojected. Full source, PCM, decoder, model and configuration pins remain in the plan. Original raw content hashes and runtime receipts remain in output. Runtime execution provenance must already have been admitted by the upstream recognition validator; lexical comparison does not independently prove which model executed.

The explicit normalization policy splits Unicode letter/number tokens including attached combining marks, preserves internal apostrophes, normalizes curly apostrophes, applies NFKC and lowercase. Original text plus UTF-16 start/end offsets and token spellings remain available. Raw tokens retain word and token indices, word strings, sample extents and window/raw hashes. There is no number expansion, Scripture-reference expansion, paraphrase, fuzzy acceptance or removal of unexplained words.

Exact token sequences are searched independently within each window. One complete match outside competing overlap is `exact-unique`; repeated matches preserve alternatives. A unique sequence intersecting an overlap remains `overlap-unresolved`. A unique canonical candidate sharing raw words with any other unit’s exact-match alternative becomes `ambiguous-unit-assignment`. A sequence crossing a window boundary is conservatively unmatched; no seam is fabricated. Other units can remain exact candidates despite their neighbors' unresolved correspondence.

Optional candidate spans explicitly identify raw word indices for diagnostics. They do not select or authorize audio. Bounded deterministic edit operations classify lexical insert/delete/replace differences and preserve both token lists; tied edit explanations are not acoustic judgments. Spans are checked against exact retained raw indices, and overlap alternatives remain visible. Raw projection retains introductory, numbering and closing material without assigning a disposition to it.

Observed word envelopes are ASR extents, explicitly not playback cuts. Every unit and report remains unqualified with empty accepted playback ranges. Quiet-boundary measurement, delivery/native clock qualification, calibrated quality and reviewed per-unit eligibility are separate requirements.

Bounds: 32 raw windows,4MiB each/16MiB combined,1MiB canonical manifest,1000 units,20000 tokens per canonical/raw side,50000 emitted evidence tokens and50000 emitted words (including repeated punctuation-only diagnostic spans),128 matches per unit,1000 diagnostic spans and256 tokens per side for each edit diagnostic. Inputs exceeding these limits refuse rather than truncate.
