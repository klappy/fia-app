# Per-unit evidence classification

A separate classifier can describe the evidence available for each exact canonical guide unit, preserving independently observed candidates alongside unresolved units. It verifies source and text bindings and reports missing or incompatible evidence explicitly.

Classification does not authorize playback or manufacture calibrated quality, browser-clock qualification, or an acceptance policy. This increment installs no public classifier route and does not connect it to fabricated recognition inputs. Its dedicated test suite is included in required Worker CI; automatic qualification and immutable publication remain separate work.
