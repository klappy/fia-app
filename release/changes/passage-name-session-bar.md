# Passage name in the session bar; Replay grays without audio

Under the six stage icons the redundant "Step N" is replaced by the current passage with its full localized book name (`<stage> · Mark 1:1–13`, `<stage> · Marcos 2:23–3:6`), taken from the catalog title and rebuilt from English or Spanish full book names when a title is missing or starts with a code; a short code is never shown. The line is `<stage> · <passage reference>` on ONE line always (captain ruling 2026-10-16: overflow is a low risk, adapt when it happens): the stage name never wraps or shrinks (only a name wider than the whole bar ends in an ellipsis instead of spilling past the edges), the passage reference takes the remaining width and ends in an ellipsis, and the band is fixed at 92 px in CSS and never grows (the `--band-height` measuring is removed). The passage part is the localized book name and chapter/verse reference only: no heading or reference title is appended. The full text stays in the spoken progress text and in the passage's `title`. Replay is disabled and grayed wherever the block has no recording, video or preparable narration (the same `slotPlays` rule as the fourth slot), and while the device check runs it stays disabled until the recording can play (`manualAvailable`, like the fourth slot's Play), so a tap never settles a block silently. The spoken progress text keeps the stage position for screen readers only (`<stage> · <passage> · stage 3 of 6 · unit …`), since the six icons that now carry it on screen are hidden from assistive tech; the visible line is unchanged, and the hosted listening journey checks the new spoken wording. Media, progress semantics and recording policy are unchanged.
