# Passage name in the session bar; Replay grays without audio

Under the six stage icons the redundant "Step N" is replaced by the current passage with its full localized book name (`<stage> · Mark 1:1–13`, `<stage> · Marcos 2:23–3:6`), taken from the catalog title and rebuilt from English or Spanish full book names when a title is missing or starts with a code; a short code is never shown. The line wraps below the icons instead of truncating, the band grows from its 92 px minimum, and the bar publishes its measured height as `--band-height` so the top glass and content start below a wrapped line. Replay is disabled and grayed wherever the block has no recording, video or preparable narration (the same `slotPlays` rule as the fourth slot), and while the device check runs it stays disabled until the recording can play (`manualAvailable`, like the fourth slot's Play), so a tap never settles a block silently. The ` · ` separator wraps with the passage, never left dangling after the stage name. The spoken progress text keeps the stage position for screen readers only (`<stage> · <passage> · stage 3 of 6 · unit …`), since the six icons that now carry it on screen are hidden from assistive tech; the visible line is unchanged. Media, progress semantics and recording policy are unchanged.
