# 3.0.0-alpha.11 — Native video owner retention

A navigation, video completion or passage selection requested during native fullscreen now retains its video element until the browser acknowledges exit. Pending transitions settle once; late events from an obsolete owner cannot affect a successor. A timeout retains the owner and offers a truthful exit notice rather than forcing removal.

Passage selection preserves the latest user intent across asynchronous loads, persists the actual selected descriptor and reports deferred load failures. No automatic playback is introduced on exit. Source recordings, proxy delivery, offline behavior, layout, CSS and original visual comparisons are unchanged.

Focused model and App regressions cover native ownership, timeout, stale events, out-of-order selection and deferred errors. Supporting browser fixtures exercise standard fullscreen and simulated WebKit exit state. They do not reproduce or prove a fix for the reported installed-iPhone freeze; physical-device verification remains required. The development → staging → production release gates remain separate.
