# 0.2.x — L3 guided flow

Train: Alpha phase 4, lane L3. Branch `alpha/l3-guided-flow` (base `alpha/l0-scaffold`).

## What this train carries

- `src/flow/` — the guided-flow core, pure and tested:
  - `catalog.ts`: thin loader over the L1 catalog (C-03 manifest) and pack guides (`guide.json` text joined onto C-04 `guide-units.json`); every document ajv-validated before use; book/pericope queries for S02/S03.
  - `model.ts`: unit order, two-level position, stops, forward-jump guard, skipped stops.
  - `machine.ts`: session state machine — idle / playing / paused / countdown / next-ready / stop / finished; one primary per state (05 § States); stop → `We talked — continue` sets `discussed`, 5 s undo clears it; Skip and jumps never mark a stop discussed; restart keeps marks.
  - `store.ts`: C-09 workspace + C-11 completion persistence behind a key-value port (localStorage); validated on save and restore; digest mismatch clears that mark and reports it; storage failure is a status; restore never autoplays.
  - `session.ts`: one external store (`useSyncExternalStore`) shared by the guide-family screens, so Guide / Text / Overview share position (R-411). No `App.tsx` change.
- Screens: S01 (pick → content language), S02 library (books from C-03, resume card), S03 pericope list, S04 passage card (includes, Start / Continue · stage / Start again), S05 guide, S06 single-script, S07 overview (glyph states, forward-jump guard), S18 completion (played vs discussed vs skipped counts), SH-2 discussion-stop sheet, SH-5 forward-jump guard.
- Tests: `tests/flow/*` (26) over a checked-in L1 sample (`tests/fixtures/flow/`: C-03 manifest cut to eng/spa/arb × Mark 1 + James 1; full eng Mark 1:1–13 guide from `alpha/l1-pipeline` @76ec277).

## Stubbed / not in this train

- Narration audio is L4's: `hasAudio` is false until L4 feeds `play` / `narration-end`; the guide shows `Continue (no audio here)` with the reason line. The machine's audio path (Play, countdown, Wait, auto-continue off) is unit-tested.
- Save/offline rows on S02–S04, S18 save row: L2.
- Explore cards and `(i) More about this`: L4 (resources). The L1 sample has no hidden regions yet.
- Settings (auto-continue toggle, group flag, theme): L5 C-10; defaults used (auto-continue on, group wording, light).
- Countdown uses 05's 2 s; PRD R-408 cites the PoC's 750 ms — flagged for a ruling.
- R-414 Scripture cue is a text heuristic (read/listen + passage title) until L1 carries a cue flag; e2e for R-407/R-414 not added (no Playwright browsers in this sandbox).
