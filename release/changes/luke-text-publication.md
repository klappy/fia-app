# Luke text in English and Spanish (Mark unchanged)

Luke joins the served catalog as text only, beside Mark: 194 compiled Luke presentations (97 English, 97 Spanish, source revision f8776d92, compiled by the existing presentation compiler) are now listed in `content/registry.json`, so every Luke passage appears in passage selection and shows its text in both languages. The catalog grows from 136 to 330 packs (Mark first, then Luke, per language). No Luke audio, video or AI content ships here: the pinned guide source has no Luke audio, so Luke audio stays a follow-on ticket (source pin plus rights acceptance); Luke ledgers stay `reviewStatus: proposed`.

Publication authority is re-pinned for the new catalog only: `trusted-generalized.json` (catalog digest and size plus 194 new Luke records; all 136 Mark records and their envelopes are unchanged) and `REGISTRY_SHA` in `guide-dispatch.mjs` (which also changes the identity of Mark guide-dispatch rows, since the registry digest is part of that identity). The pack id checks accept `LUK-` beside `MRK-` in the browser library, media delivery, read and executable operations, the executable presentation resolver, the generalized snapshot, the Worker snapshot store and the guide-source export. The 330-pack catalog is 2.67 MB, so the catalog alone may be up to 4 MiB (Worker static read, generalized snapshot, guide dispatch and guide executor); every presentation keeps its 1 MiB cap. `BACKEND-CLOSURE.json` and the release closure are re-pinned to these exact bytes.

Mark is unchanged: every Mark presentation file is byte-identical, the 136 Mark registry descriptors are identical and in the same order, and Mark offline manifests differ only by the app shell (`index.html`, the JS bundle) and the shared catalog.
