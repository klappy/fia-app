# 3.0.2 audio-master-alone release preparation

Version `3.0.2` is production 3.0.1 (`628a898`) plus the audio-master inversion alone (PR361, merge `9068ad3`). It is reached on `main` by reverting `f74daec`, the revert that took PR361 off `main` for the highlight-only release. Outside `package.json`, `package-lock.json`, `CHANGELOG.md`, this note and the release-closure pins, the tree differs from production only in the ten files of PR361.

## Why

PR361 was reverted only so that 3.0.1 could carry the highlight change alone. Of the three merges reverted for that release it is the one that touches no content pack, server or service worker file. The Spanish Luke recompile (PR356) replaces published passage revisions, and a saved copy whose revision the server no longer holds is revoked by the service worker (defect D1). Restoring PR361 by itself lets audio-master reach DEV while a promotion from `main` still replaces no published passage revision.

## What is in it

The audio-master change as described in [2026-11-09-audio-master.md](2026-11-09-audio-master.md): a recorded guide stage opens one media session for a run of consecutive same-file clips, the pages turn by the player clock, both pause when the audio pauses, and Next, Back, swipes and the Overview seek the running session to the chosen screen. The planner keeps the identity, source-pin, mapping and verified-timing checks; a run that cannot be planned plays each screen's clip on its own as before.

The revert conflicts only in the generated release-closure pins, which are regenerated. Nine of PR361's ten files are the same blobs as at `9068ad3`; `apps/web/src/App.svelte` differs from `9068ad3` only where PR356's lines are absent.

## Pack safety

`apps/web/public/content`, `server/` and `apps/web/public/sw.js` are the same git objects as on the `production` branch, and the generated worker snapshot (`server/faces/worker/generated/snapshot.json`) has the same sha256 as a build of production: `ceecf730edbff91bee731715b2c975f302f57365b6c3fa43873e52bf48b72449`. No published passage revision is replaced and the service worker source is production's. The app bundle is new.

## Not in it

PR356 (Spanish Luke honest-text recompile, which also carried the 3.1.0 release prep) and PR360 (saved-pack worker change) stay reverted on `main`. Defect D1 is not fixed. Draft PR364, which restores all three reverted merges together, stays a draft; after this version it needs a rebase and then restores PR356 and PR360 only.

## Limits

This version is held from production until a physical iPhone pass. The evidence so far is synthetic-clock tests, in which the tests drive the player clock, and one desktop Chromium run in which English Mark 1:1–13 opened and played; neither certifies acoustic synchronization on a device. No phone, iOS Safari or installed home-screen app has been used, and no upgrade from production's build to this one has been rehearsed. Each environment still requires independent review, required checks and exact-commit post-deploy evidence under `RELEASING.md`. This note does not merge or deploy anything.
