# One recording session for an authored together-screen

Together-screen guide lists use one verified recording and one continuous outer range. Internal row progress and highlighting follow the same media clock, preserving source pauses without per-row stop/seek/play cycles or scheduled delays. Only the final row receives the existing bounded tail policy. Replay restarts the authored screen; pause/resume and navigation retain their existing ownership.

Eligibility requires the exact existing together/automatic list contract, consecutive guide rows, matching verified source/delivery/clock identities and valid ordered ranges. Separate discussion questions remain separate. No timing guard is relaxed and no source audio or word timing is invented. Existing rejected word maps remain untimed; the analysis-only alternative S03 maps are not runtime admissions. Native audible/device acceptance and unavailable exact local audio bytes remain explicit gates.
