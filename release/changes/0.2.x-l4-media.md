# 0.2.x — L4 media

Train: Alpha phase 4, lane L4. Branch `alpha/l4-media`. Covers R-501..R-511 (see PR body for done / stubbed).

## What this train carries

- `src/media/` logic, pure and tested (`tests/media.test.ts`, fixture `tests/fixtures/media/` trimmed from L1 packs; alignment sidecar synthetic):
  - `alignment.ts` — C-12 validator (monotonic, within duration, word ranges in text, no overlap), hash binding (a sidecar for another recording is silently unused), highlight-from-elapsed, tap-to-seek, edition switch keeps position by verse, token-based verse split.
  - `seek.ts` — slider on every clip > 30 s (R-505), clamped seeks, clock, resume per clip hash, primary phase.
  - `provenance.ts` — C-06 → user-word marks; AI always marked, never shown as source (a conflicting `ai: true` wins); Scripture text never AI (throws / refused); narration modes (R-501/R-502); SH-1 sheet model per spec 20.
  - `narration.ts` — C-05 entries → source/generated clips; stale clips (text sha mismatch) refused.
  - `scripture.ts`, `resources.ts` — reader editions with the R-305 English fallback; catalog cards (R-508), chip counts, diacritic-insensitive search, offline captions.
- Screens S08–S12 and SH-1 built on those modules; packs load from `${VITE_CONTENT_BASE:-/content}/packs/<packId>/<file>.json`.
- Component bodies: `AudioControls` (slider only > 30 s, mark opens SH-1, replay-verse, hint), `MediaViewer` (pinch-zoom + double-tap, frame messages, video events), `ProvenanceMark` (optional info button).

## Not in this train (Bide)

- Audio for Scripture/guide: L1 ships `narration.json` empty; AI narration is generated later server-side and will be marked. Screens show the absent mark, no disabled primary.
- Alignment sidecars: none in L1 yet; the reader loads `alignment/scripture-<edition>.json` when present.
- Describe (R-509) narration and AI description text: slot absent in L1; the pill is disabled and marked.
- Narration mode is fixed at the R-501 default until L5 settings (C-10) land.
- SH-1 source line (`s.prov.source`, spec 20 / R-312): rendered with holder and licence in `dir="ltr"` spans when the caller passes the rights record; L1 packs carry no holder/licence yet, so the line stays hidden (never shown with holes) until they do.
- AI term audio (R-501 fallback for key terms): S10 offers no generated clip until L1 emits one; the mark stays honest (◌).
- R-510 audition and R-511 manifest fields are pipeline/L5 concerns; nothing here.
