# Offer a no-video download package and show each package's size

The Downloads sheet adds a no-video package (text, audio, images and maps) between Text and audio and the full package, labels Text only as the small default, and shows each package's total computed from the passage manifest at the sizes it would request. The no-video package is offered only when a pack has images or maps as well as video, so it never repeats Text and audio. The service worker saves no video files for it, and Remove also deletes a saved no-video copy. Offline, an unsaved video shows a plain note instead of a player, unless a load already in progress or failed still needs its Cancel loading or Try again button. Existing Text only, Text and audio and full packages, media delivery and recording policy are unchanged.
