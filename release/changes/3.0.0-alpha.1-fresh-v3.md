## Deployment and rollback

Existing Wrangler configuration and Git hooks remain: `main` → dev, then `staging`, then `production`, using reviewed merge commits and verifying each deployed identity before the next promotion. `/version.json` is no-store. Each environment's commit differs while the reviewed application tree is preserved. Cloudflare attestation is unavailable where no run URL is supplied.

The active `/sw.js` registers the approved offline protocol; it does not retire itself. It validates downloaded bytes, stages incomplete transfers, preserves the previous active copy until a verified update completes, and handles media ranges. Removing downloaded content preserves progress/preferences. Browser storage can be evicted; disconnected old clients cannot receive a new deployment. No migration of old application progress into this pack is claimed.

Rollback follows `RELEASING.md`: revert the promotion through review, verify its new deployed stamp and post-deploy check. The tested upgrade preserves prior caches/local storage; rollback behavior is not a substitute for device validation.
