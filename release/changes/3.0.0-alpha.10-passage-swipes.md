# Guarded passage swipes

A left swipe invokes existing Next and a right swipe invokes Back. Recognition requires 60px horizontal travel, a 1.5:1 horizontal ratio and completion within 700ms. Screen-edge 24px regions, vertical scrolling, selected text, controls, media and dialogs are excluded. Activity/pack changes invalidate pending gestures; an obsolete selection cannot leave navigation blocked after the latest load finishes.

The existing navigation actions preserve progress and cancel stale media ownership. Swiping to a prepared image authorizes only that current visual; Back aborts its unfinished request. The FIA Guide title, approved branding, on-demand playback, timing mappings and original spacing remain unchanged. No CSS or spacing revision is included.
