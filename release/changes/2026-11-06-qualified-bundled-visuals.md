# Qualified existing bundled images and maps

Connect eight existing published static payloads to 46 independently qualified asset bindings across 24 English/Spanish Mark/Luke presentations. Four map bindings belong to the original English Mark passage; the other 42 bindings are images. This is bounded reuse of existing bytes, not new publisher acquisition or full-corpus media completion.

The separate bundled-static route verifies the current presentation and complete authored asset, the pinned qualification/rights identity, fixed ASSETS path, actual bytes, MIME and current decode/pixel proof. Default approved assets and canonical source-backed assets use explicit distinct binding cases. No arbitrary URL, publisher/R2 custody claim or acquisition path is added.

The service worker validates the immutable qualified descriptor before joining its context to an existing media generation. Classic audio keeps its generation. Explicit image viewing, optional saving and cold offline restoration preserve the same source binding; the remote-original contract remains separate.

Focused server, service-worker and App tests cover real retained bytes, context generations, online viewing, saved offline restoration and refusals. The packaged Worker check verifies all 24 manifests and all 46 byte responses through actual ASSETS; browser checks verify natural image dimensions and byte hashes in each book/language group. Each candidate still requires its own successful build, release checks, independent review and deployment evidence.

No translations, voices or new editorial relationships are invented. Remaining publisher assets, whole-corpus audio, human Spanish/voice review, physical devices and full media acceptance remain outside this bounded increment. The previously accepted passage-switch disposition is unchanged.
