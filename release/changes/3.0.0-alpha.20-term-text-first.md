# Text-first word meanings — 3.0.0-alpha.20

Release metadata for the increment already merged on main through `f82dde1633119f960cea775e9e03949e560a0f89`: PR265, then PR284. This release preparation is metadata only; it adds no runtime behavior of its own. The visible change is PR265's text-first term flow.

- Text-first term steps: in text-first or no-recording use, Continue now shows the term's definition on the same step before moving on.
- Offline Text-only: the term instruction no longer disappears when recordings are removed for offline Text-only use.
- Word-meaning labels: the English verified-source headword labels are improved; the Spanish baseline labels are kept.
- Visual originals (PR284, server only): reviewed image and map originals can be fetched and retained in custody. This is custody-only: the decoder is unavailable, and no image or map is shown or delivered to users.

Known gaps remain explicit: Spanish localization labels are still a known gap; resource (image and map) delivery is not part of this release. The hosted browser term-flow proof passed on DEV at source merge a82ec1a (PR265), and main f82dde1 passed CI and DEV; physical-device, audible and whole-corpus acceptance are not part of this release.

The alpha19 baseline does not qualify this bumped candidate. The release owner must collect fresh exact-candidate review, required checks and DEV → staging → production deployment proofs for this candidate through the existing sequential release process.
