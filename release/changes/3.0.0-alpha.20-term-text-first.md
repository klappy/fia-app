Release metadata for the increment already merged through `a82ec1a1deaed3536409af3193b4e557c7984063` (PR265). This release preparation is metadata only; it carries runtime behavior from PR265 only.

- Text-first term steps: in text-first or no-recording use, Continue now shows the term's definition on the same step before moving on.
