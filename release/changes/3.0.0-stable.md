# 3.0.0 stable release preparation

The next FIA release uses stable SemVer `3.0.0`, graduating the existing `3.0.0-alpha.21` series without an alpha or beta suffix. Package metadata and the lockfile agree; generated version stamps read the package version.

This release preparation accompanies the continuous-reading candidate and retains previously integrated text/resource access, audio identity validation, verified visual routing and the approved guide layout. Continuous-reading behavior is subject to the integration owner's final tests and independent review. It adds no translation, recording, word timings or media admission.

The stable label is not a whole-corpus or device acceptance claim. Full audio/highlight synchronization, human Spanish review, physical audible acceptance and unavailable media remain outside the demonstrated scope. First-step timing and the accepted passage-switch issue remain follow-up limits. Existing bounded browser and component receipts must keep their original runtime identities and scopes.

Before promotion: finish implementation review and tests; regenerate release closure after integration; build and verify `version.json` reports `3.0.0` at the exact candidate commit; run required release checks; obtain fresh independent review and DEV → staging → production post-deploy receipts under `RELEASING.md`. This local metadata change does not merge or deploy anything.
