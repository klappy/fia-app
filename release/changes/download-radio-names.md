# Keep each Downloads package radio's name to its package label

Each package radio in the Downloads sheet is named by its package label alone (Text only, Text and audio, Text, audio, images and maps, Text and all available resources). The package name, size and note added in fia-app#248 are now the radio's description, so screen readers announce the label first and the size second, and a changing size no longer changes the radio's name. What the sheet shows and downloads is unchanged.
