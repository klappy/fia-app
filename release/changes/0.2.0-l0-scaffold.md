# 0.2.0 — L0 scaffold

Train: Alpha phase 4, lane L0. Branch `alpha/l0-scaffold`.

## What this train carries

- Repo bootstrapped as MIT © 2026 Word Collective (`LICENSE`, `package.json` license field), `README.md`, `NOTICE.md` stub.
- App skeleton: Vite 7 + React 19 + TypeScript, `react-router-dom` routes for S01–S19 and SH-1–SH-5, `vite-plugin-pwa` manifest and a generated service worker (L2 owns the real offline SW).
- `src/tokens/alpha.css` generated from `design/tokens.json` (copied from the cookbook `design/alpha-system/tokens.json` 0.1.0-draft): light/dark colors, type scale with large-print steps, spacing, radius, elevation, motion + reduced motion, safe areas, per-script fonts via `:lang()`.
- `src/i18n/en.json` generated from every `| \`s.x.y\` | English |`table row in the 24 screen specs plus`s.common.*`; loader with ICU-placeholder substitution (plural: minimal `one/other`).
- 17 Aquifer FIA languages with autonyms in `src/i18n/languages.ts`.
- 20 design-system component stubs with typed props and a `state` prop; dock and More sheet.
- `contracts/` — 18 schemas verbatim; `src/contracts/validate.ts` (ajv 2020 with local registry); `tests/contracts.test.ts` validates every schema's `examples[0]`.
- CI (`.github/workflows/ci.yml`): npm ci · lint · typecheck · vitest · vite build · playwright smoke (S01 shows the language list).
- `wrangler.jsonc` for Workers static assets: `name` fia-app, `workers_dev: true`, `env.dev` (fia-app-dev, branch main → dev.fiaguide.app), `env.staging` (fia-app-staging, branch staging → staging.fiaguide.app), `env.production` (fia-app, branch production → fiaguide.app); no routes in the file, custom domains attached account-side. Build command `npm run build` = `vite build` only; tests gate the PR, never the deploy build.

## Not in this train

- Real content loading (L1 pipeline), the ported offline SW (L2), audio transport, workspace persistence, journeys beyond the S01 smoke.
- PORT items from the PoC (`install.js`, `narration.js`, `guide-completion.js`, SW): follow-on lanes.

## Verify

`npm run lint && npm run typecheck && npx vitest run && npm run build && npx playwright test`
