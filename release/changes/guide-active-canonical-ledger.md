# Durable guide preparation and complete canonical ledger

Trusted guide preparation can persist a queued attempt and execute it through a Durable Object alarm. Interrupted preparing attempts become uncertain without automatic retry; an explicitly requested, newly authorized queued attempt can rearm. Authority is checked again before final publication of the review-required receipt. Default hosted recognition capabilities remain absent, so this change does not expand accepted recording coverage.

A separately verified canonical-unit ledger retains every P1 source unit, including associated pause instructions and nonspoken production notes. The loader owns its input bytes before asynchronous verification. This preserves complete source accounting without inventing spoken activities or changing approved presentation text; executor integration and accepted range publication remain follow-on work.
