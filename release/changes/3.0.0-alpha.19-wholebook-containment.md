# Whole-book saving containment — 3.0.0-alpha.19

Release metadata for the increment already merged through `377231d9990ee52936c27670f11012f5f6cdb36b` (PR277). This release preparation is metadata only and adds no runtime behavior beyond PR277.

- Client containment: the updated Downloads sheet marks whole-book saving temporarily unavailable; per-passage saving remains available. See [whole-book saving](whole-book-download.md).
- Worker guard: the worker refuses to replace a verified executable Saved snapshot with a base or snapshot-less save, PR277.

Known limits remain explicit: first saves without a prior executable Saved snapshot are outside the guard; already-loaded old clients and offline workers must update before the guard applies to them; snapshots already replaced are not recovered; and a rejected old-client save can leave an unreferenced `-repair` artifact cache, which is known storage overhead with a follow-up queued.
