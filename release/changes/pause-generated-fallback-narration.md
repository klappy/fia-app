# Pause generated fallback narration

Generated fallback recordings are paused. Original publisher recordings remain available where verified, and content without an original recording remains readable.

The build applies the policy after verified original guide and Scripture replacements. For the approved English Mark1:1–13 inventory,112 original replacements remain (111guide recordings and the BSB recording);31 generated fallback paths are excluded. Saved generated descriptors are hidden and their cached playback is blocked without deleting historical bytes. About and listening settings describe current availability without presenting historical inventory counts as playable recordings.

Existing source provenance, byte verification and explicit playback controls remain. This change does not add Mark/Luke coverage or fix the separately tracked preparing-response offline-retention issue.

Validation: production build, policy/offline regression tests, source publication tests and refreshed release closure checks. Hosted qualification is required for each promoted commit; local tests are not deployment evidence.
