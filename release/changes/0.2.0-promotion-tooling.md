# 0.2.0 — promotion tooling

Branch `alpha/promotion-tooling`. Adds the routine and the gate for dev → staging → production.

## What this carries

- Build stamp: `vite.config.ts` emits `dist/version.json` `{ version, commit, branch, builtAt }` (commit from `WORKERS_CI_COMMIT_SHA` → `GITHUB_SHA` → git); excluded from the PWA precache; `public/_headers` serves it `Cache-Control: no-store`.
- Playwright honors `BASE_URL` (no local server when set); `e2e/deployed.spec.ts` checks the stamp and `EXPECT_COMMIT`; `npm run smoke:deployed` runs it with the S01 smoke.
- `.github/workflows/post-deploy.yml`: on push to `main`/`staging`/`production` (or by hand) waits for the env to serve the pushed commit, then runs the deployed smoke. Read-only (`contents: read`).
- `RELEASING.md`: promotion routine, rollback, hotfix.

## Not in this train

- No version bump (release prep is its own PR per `RELEASING.md`). No infra, secrets, dashboard or branch-protection changes.

## Verify

`npm run build && cat dist/version.json && npx playwright test` · `BASE_URL=https://dev.fiaguide.app npm run smoke:deployed`
