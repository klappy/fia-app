# Play prepared recordings without downloading the whole passage

Explicit Play now fetches and verifies the selected prepared recording. An active listening session can continue to the next needed clip; load, restore, pack selection and settings changes do not grant playback consent or prefetch media. Pause/navigation cancel pending delivery and scheduled starts. If the browser requires a fresh gesture after verification, the existing Resume control retries the same verified audio owner synchronously without another fetch.

The first English Mark1:1–13 pack publishes source-bound proxy derivatives for143 existing recordings and8 images/maps. Optimized output bytes, sizes, MIME, options and SHA256 identities are distinct from immutable original sources. Audio uses the accepted voice/medium Opus profile; images use medium WebP. Downloads save the same verified output under the logical source path for offline use. Delivery reads enforce an incremental byte ceiling and whole-file integrity before playback; this is not progressive streaming and larger files may require a transfer/verification wait.
