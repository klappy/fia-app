# Clearer original-recording availability

The passage list now identifies reviewed guide recordings that can be prepared on request, instead of calling those recordings unavailable. This is a build-time projection of exact reviewed pack, revision, language, and edition identity; it does not fetch audio or imply that preparation is already complete.

The ready prompt clears when the matching recording actually starts playing, so it no longer tells a facilitator to press Play during playback. Explicit Play remains required, and failed or unrelated playback does not dismiss the prompt.

These changes address confusion observed in the DEV facilitator journey. They add no accepted recordings, preparation authority, provider calls, infrastructure, or video changes. Candidate browser/persona and visual verification remain separate from the reviewed source tests.
