# Stand-in narration (F5)

`eng.MRK-1-1-13.narration.json` is a **stand-in** C-05 narration manifest (contracts/c05-narration-manifest.schema.json) for the pack `eng.MRK-1-1-13`. It points at the PoC's live AI-voiced clips on `https://fia.klappy.dev` (klappy/fia-functional-poc @62a979f), as the captain ruled on 2026-10-02 ~17:22 ET (cookbook `work/active/2026-10-01-fia-alpha-v2/RULING.md`, last section): the guide is built now, in the frozen data shape, and lane B's B2b pack replaces it later with no screen change. The pack's own `data/packs/eng.MRK-1-1-13/narration.json` wins as soon as it lists clips (`src/media/standin.ts` `narrationSource`).

- **Built by** `node scripts/standin-narration.mjs <fia-functional-poc checkout>`: it reads the PoC manifests at the pinned commit with `git show`, binds each clip to the app unit whose C-04 `textSha256` equals the PoC entry's `sourceSha256`, recomputes `bytes` and `sha256` from the git blob (they must equal the PoC manifest) and measures `durationSeconds` with ffprobe.
- **Which clip per unit** follows the PoC (`src/lib/audio.js:9`, `approvedAudioManifest` order): its 19 reviewed next-action adaptations and 4 activity-transition "with-pause" clips first, then the unit recordings. The 23 adapted clips speak the PoC's reviewed pause wording ("I will pause the audio here …") and are bound to the unit text as the PoC binds them. They are listed in `eng.MRK-1-1-13.standin.json` `.adapted`.
- **Every clip is AI-voiced** (`ai: true`, `recordingSource: generated`) and carries C-06 provenance `generatedFrom: fia-functional-poc@62a979f…:<PoC manifest>#<unit>`, generator `narration`. The voice label `eng-poc-narrator` is an app label, never the provider's voice id. `audited` is absent: no native-speaker audition is claimed.
- **Silent units** (17, `.silent`): the 13 hidden drama-example units S04-U017–U029 (the PoC has no clip for them) and the 4 attached pause cues S02-U012, S06-U005, S06-U007, S06-U009, whose words the PoC speaks inside the parent's with-pause clip. They show their text with no voice.
- **Streaming only.** The PoC host sends no `Access-Control-Allow-Origin` header, so the clips play through the media element and are never fetched by script or saved for offline. Offline audio is B2b/BL3.
- **Not here:** Scripture clips (F6-S08), key-term and description clips, and meeting point M, which is checked on B2b's own clip on DEV (G-B).
